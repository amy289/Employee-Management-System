# Lab 9 — PHP Fundamentals: Employee Management System

## Features
- Employee list, create form and detail page
- POST form processing and server-side validation
- Reusable `include` files for header/footer
- Session-based login gate and logout
- Output escaping with `htmlspecialchars()`

## Requirements
- PHP 8+
- XAMPP (Apache)

## Run
1. Extract the ZIP.
2. Copy the `Lab9_Employee_Management_System` folder into `C:\xampp\htdocs\`.
3. Start **Apache** in XAMPP.
4. Open `http://localhost/Lab9_Employee_Management_System/login.php`.
5. Demo login: username `admin`, password `Lab9Demo!`.

## Important
This Lab 9 project intentionally demonstrates PHP fundamentals without a database. Employee records are stored in the PHP session and reset when the session ends. The hard-coded login is for classroom demonstration only, not production use. Do not publish real credentials.
